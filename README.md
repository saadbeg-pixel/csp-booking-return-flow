# CSP Booking — Accepted Booking Return Flow

Design spec for the Wiom Partner App: once a partner accepts a booking, tapping it
from Home reopens the installation-day screen, and back from that screen shows the
booking card in an Accepted version ("इंस्टालेशन का दिन देखें" / "कनेक्शन नहीं लगा सकता",
✕ closes directly). The booking state is never undone.

`index.html` is a self-contained page, published at
https://saadbeg-pixel.github.io/csp-booking-return-flow/

**Internal-facing.** Excluded from search engines (noindex + robots.txt), but anyone
with the link can read it.
